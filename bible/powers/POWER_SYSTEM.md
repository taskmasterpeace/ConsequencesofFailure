# COF POWER INDEX (CPI) — the no-plot-armor system  `[PROPOSED v0.1 — architecture]`

**Why this exists:** so that whenever two characters meet — anywhere in the world, powered or not — we can say *who wins and why* from the numbers, not from plot convenience. Inspired by the **FASERIP** tabletop model (ranked attributes + a universal scale), rebuilt for COF's geopolitical, quantified, no-plot-armor world. Pairs with the Country Master Sheet (national-scale quantification) and `bible/VISION_AND_GOALS.md` §4.

## 1. The Rank Ladder (one scale for everything)
Every measurable thing — an attribute, a power's intensity, a wall's durability — sits on **one ordered ladder 0–9 (+X):**

| Rank | Meaning |
|---|---|
| 0 | Negligible |
| 1 | Average human |
| 2 | Peak human (Olympian, elite soldier) |
| 3 | Enhanced (low-tier LSW) |
| 4 | Superhuman |
| 5 | City-block scale |
| 6 | City / regional scale |
| 7 | National scale |
| 8 | Continental scale |
| 9 | World-ending |
| **X** | Cosmic — **reserved for the Alliance of Four / Iron Eaters** |

**Ceiling rule `[fork]`:** human LSWs cap around **7–8**; **9–X is alien-only.** This protects stakes and stops power-creep — the scariest human is still below the threat the whole series is counting down to. *(Map the legacy "LSW Level 1–5" onto this: Lv1≈3 … Lv5≈7. Confirm.)*

## 2. The Seven Attributes (COF's "FASERIP")
Every character — **including non-powered leads** — is rated 0–9 on:
- **MIGHT** — raw force / strength
- **FINESSE** — agility, reflexes, combat skill
- **BODY** — durability, endurance, constitution
- **MIND** — reason, knowledge (a Sage spikes this — see §6)
- **INSTINCT** — perception, intuition, awareness
- **WILL** — resolve, mental defense
- **PRESENCE** — influence, command, manipulation *(load-bearing in a geopolitical story — this is how Charles Sapphire or a president "wins" a scene)*

## 3. The Power Profile (where no-plot-armor lives)
A power is **statted, not vibed.** Each gets:
- **Intensity** (ladder rank) · **Range / Area / Duration**
- **Cost / Drawback** — **mandatory.** Every power has a real price. *(Jawah caps ≤70 dB; Kaiser's Memory Vessel cost scales with how wide he opens; Asha's trips cost memory/sanity; Stampede's Swallow physically wrecks him.)*
- **Requirement / Lock** — a condition to use it *(Stampede must "know the space"; the Xanthi need an anchor)*
- **Scaling** — can it grow, and how *(Jawah's dB ceiling rises with mastery)*
- **Counters** — what neutralizes it *(sound power vs a vacuum; the Xanthi vs anchor-severing)*

## 4. Resolution (how a fight is called)
1. Pick the contested axis (e.g. attacker's power **Intensity** vs defender's relevant **attribute**).
2. **Rank gap = edge.** Equal ≈ contest/luck. A **2+ gap = dominance** —
3. *unless* a **Counter, Cost, or unmet Requirement** flips it. **That gap-flipper is your drama.** If nothing flips it, the higher number wins. No convenient miracles.

## 5. Power-source tags (drive interactions)
`Grey-LSW` · `Sage` (knowledge-type) · `Symbiont` (Moses, Kaiser) · `Tech` (NuroNuro, RoboForge) · `Precursor` (Iron Eater) · `Baseline` (non-powered). Some matchups key off source — tech vs EMP, symbiont vs host-death, sound vs vacuum.

## 6. The Sage exception (knowledge ≠ experience)
A Sage is **MIND 9 in ONE college course** but **APPLICATION ~1** — all the knowledge, none of the practice; brilliant and helpless, dependent on resources. Stat them as two numbers: **Knowledge (high) / Application (low).** *(Matches `bible/powers/SAGES.md`; the college-course source is a late reveal.)*
